# Community expectations

Be respectful, constructive, and welcoming. Discuss code and behavior rather than attacking people.
Harassment, discrimination, threats, spam, and disclosure of someone else's private information are not welcome.

Use sanitized examples and respect consent when sharing screenshots, conversations or recordings.
Maintainers may edit or remove abusive content, close disruptive discussions, or limit participation.

To report harmful behavior, ask a maintainer for a private contact channel without disclosing sensitive
details publicly. A named private contact must be established before the public launch.
These expectations apply to this project's issues, pull requests and discussions.
