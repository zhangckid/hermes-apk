# catgo-gpt 1.2.0

- 服务器设置下方和登录页新增独立 SSH 调试入口；域名/IP、端口、用户名、密码可配置，默认端口 22。
- 首次连接核对 SHA-256 主机指纹；变化时拦截并要求重新核对。可选 Keystore 加密记住 SSH 密码，不复用聊天凭据。
- 密码认证的交互式行终端：中文输出、连续命令、Tab/Enter/Ctrl-C、跟随输出、清空显示。返回会断开 SSH，输出在内存保留，最多 64 Ki 字符；不自动执行或重发命令。
- 支持中文/English 应用语言设置并持久化，158 项配对资源。系统语音识别跟随选择；聊天正文、SSH 输出及远端 LANG 不修改。
- SSH 页面切换保留聊天草稿，取消握手关闭底层 socket。

验证使用绑定 127.0.0.1 随机端口的隔离 SSH 服务与临时账号，覆盖未信任/变化指纹在认证前拒绝、错误密码、真实中文命令输出、同一 shell 的工作目录、断开后发送与握手取消。另有中英文资源完整性检查。没有连接用户远程 SSH 服务或修改系统 sshd。

范围限制：目前不含私钥/MFA/SFTP，不支持 vim/top 等全屏终端程序。无 Android 真机连接，设备语言切换、键盘布局及实际服务器兼容性仍需安装验收。

最终结果：45 个测试通过，1 个需显式开启的 Hermes 远程测试跳过。Debug/Release 构建通过；Lint 为 0 错误、32 警告。交付为已签名 Debug 测试包，Release 构建产物未签名。
