# catgo-gpt 1.1.0

## 修改

1. 键盘：Activity 使用 adjustResize；聊天历史与输入栏放在同一有界布局，IME/导航栏边距只消费一次，移除顶栏重复状态栏边距。
2. 朗读：详细回答保持原样，朗读生成最多约 280 字的提取式概要；优先可用中文语音与本地语音，尝试其他已安装引擎，缺失语音包时显示设置入口。切会话或关闭开关停止播放。
3. 模型：顶部入口读取服务器模型列表，提供 reasoning 档位。与网页版共享 default 配置，应用后新建会话；费用确认必须由用户再次点击。
4. 颜文字：跨帧解码 ANSI/UTF-8，独立保留最近有效状态，工具日志不会挤掉颜文字；每次连接单独维护就绪缓冲。
5. 配置：成功登录后用 Keystore 加密保存密码及 Cookie；短暂断网不清除配置，明确 401 才尝试凭据续登；退出登录清除凭据。旧版需重新成功登录一次才能保存密码。
6. 语音输入：中文优先，最终结果自动发送，防止系统识别重复回调；切会话销毁该会话的语音组件，避免跨会话误发。
7. 聊天距离：工具消息、空白及携带工具调用的中间助手消息不生成消息行；等待区保留一行状态。
8. 审查修复：取消真实 HTTP 请求、串行认证恢复、账号切换清理缓存、每会话独立 attach ID、超时退出生成状态、严格按当前用户消息匹配最终回复、取消盲目重发、重联空结果保留历史。
9. 多余 lll：发送前清空终端残留编辑行，使用括号粘贴并单独发送回车；跨帧 ANSI 解码不再泄漏控制序列末尾 l。合法用户输入的 lll 不会被删除。

采用原生聊天应用常见的单向数据流与分层职责；未使用或声称获得 Claude/Gemini/ChatGPT 的内部源码。展示规则、会话策略、语音控制、模型配置与终端解码分别拆分，便于独立测试。

## 验证范围

本地最终结果：40 个测试通过，1 个显式开启的实时服务用例在常规测试中跳过；Debug/Release 构建通过，Lint 为 0 错误、27 个警告。Release 产物未签名，交付 APK 为已签名 Debug 测试版。

- 新增自动回归覆盖 ANSI 所有拆分位置、UTF-8 中文/表情拆分、残留输入清理、合法 lll 保留、长工具日志、缓存保留、重复问题轮次匹配、工具中间回复与精简朗读。
- 实际服务器第一次测试：新建会话，先模拟终端残留 lll，再用应用发送协议发中文；服务端用户消息逐字相同、无重复，并返回“中文连接正常”。测试会话：20260907_110556_0f924f。
- 首次重联测试没有收到会话 ID 通知，该通知不能单独证明重联失败或成功。测试已加强为重联后发送第二条消息并核对同会话历史。
- 加强后的重联用例未完成：后续直连出现 NoRouteToHostException，经环境代理出现握手 EOF；独立 HTTP 检查也无法访问测试站点。没有降低 TLS 校验来绕过问题。
- 未修改真实服务器模型/reasoning 设置；验证了选项读取，实际设置写入需要在可用服务器继续验收。
- adb 无连接设备。键盘几何、第三方输入法、系统/离线麦克风及中文 TTS 发声、锁屏恢复仍需真机验收。不能把协议测试等同于这些交互均已通过。

这是可安装的调试测试版，不声明以上尚未完成的端到端和真机验证已经通过。
