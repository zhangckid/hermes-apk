# catgo-gpt 1.3.1 SSH 直接输入与离线语音优先

版本：1.3.1-debug，versionCode 17。安装包：catgo-gpt-v1.3.1-debug.apk。
签名与 1.3.0-debug 一致，可覆盖安装并保留配置。

## SSH

- 按用户要求移除 SSH 页底部的“命令或回答”输入框。点击终端或“键盘”使用原生输入连接，
  中文候选确认后直接送入当前 SSH 连接，回车执行；不会先保存在一个独立命令框里。
- 原生输入的文字、回车、退格、Tab、Esc、Ctrl-C 等直接进入有序 SSH 发送队列，
  不再经过“Android → JavaScript → Android”的往返。方向键仍尊重终端的应用光标模式。
- 断线、换终端或输入连接失效后拒绝迟到的输入；不自动重发命令。密码由远端终端的回显模式控制，
  不再提供独立的密码遮罩输入框。不要在普通 shell 提示符下输入密码。
- 终端在可见且窗口获得焦点时，若约 10 秒没有确认绘制，停止输入并提示显示未响应，
  关闭该 SSH 连接，避免用户误以为没执行而重复发送。后台暂停渲染不按这个条件判失败。
  这属于故障检测，不等于已经查明特定手机为何丢失绘制确认。

## 语音

- 每次打开语音窗口默认使用应用自带的离线识别，不预先创建或调用系统识别服务。
- 用户点击“尝试系统语音”后才尝试其他系统识别路径，可切回离线；重开窗口再次默认离线。
- 窗口显示离线准备、下载、录音和识别状态；识别成功后沿用自动发送行为。
  首次使用需下载约 75 MB 模型，之后识别在本机完成；系统识别是否联网由系统服务决定。
- 关闭窗口或切换方式时停止录音、取消未完成下载；模型准备串行化，避免快速切换时互相删除缓存。
  中文和英文界面均补充了相应提示。

## 本机验证与边界

新增完整 SSH 页面测试启动绑定 127.0.0.1 随机端口的隔离 SSH 服务，使用临时测试账号、
本机 script PTY 和 /bin/sh，不连接用户服务，也不执行 root 命令。

验证链路为：完整页面键盘请求 → Android 原生 InputConnection → 实际 SshViewModel →
有序发送队列 → SSH 服务 → 本机 PTY shell 执行 → SSH 输出 → WebView 绘制脚本。
中文命令的执行通过临时结果文件确认，回显通过独立返回标记确认；未确认候选和未按回车不执行。

还通过故障注入复现了“命令执行但画面不再更新”：模拟渲染器宣布就绪后不确认绘制，
旧实现一直等待且不报错；新版测试要求检测到超时并停止输入。

Robolectric 不运行 Gboard 或 Chromium：它的 WebView 焦点委托是空代理，测试只能确认原生
键盘请求已发出，并主动交付输入连接事件；渲染脚本由测试探针确认。另有独立的 Chromium
终端测试覆盖实际 JavaScript 渲染。这些不是实体 Android 手机的端到端测试，不能断言已排除
用户设备上的所有问题，也没有用本机结果代替远程服务验证。

## 手机验收

1. 覆盖安装 1.3.1-debug，无需卸载。SSH 页应不再出现底部命令输入框。
2. 连接 SSH，点“键盘”，用 Gboard 输入 `echo 中文`，按回车，确认终端显示结果。
3. 测试退格、Tab、方向键和 Ctrl-C；若出现“终端显示未响应”，不要反复发送同一命令。
4. 打开语音窗口，确认默认离线。需要其他方式时主动点击“尝试系统语音”。
