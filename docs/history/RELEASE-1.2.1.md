# catgo-gpt 1.2.1 测试版

版本：1.2.1（versionCode 13）。安装包：catgo-gpt-v1.2.1-debug.apk。
使用与 1.2.0 相同的 Debug 签名，可覆盖安装并保留设置。
Release 构建也已通过，但尚未配置正式发行签名。

## SSH 显示

此前使用 dumb PTY、ANSI 剥离器和普通 Text 日志，不能正确表达 zsh 重绘和终端光标。
现改为 xterm-256color + 随 APK 离线打包的 xterm.js、Unicode11 与等宽 Nerd Font。
支持颜色、中文宽字符、光标、清屏、备用屏幕、直接输入、常用特殊键和字号调整。
键盘/窗口变化同步 PTY 行列；旋转保留模拟器，断开保留屏幕，重新连接开始新终端。
复制当前选区；没有选区时复制可见屏幕。按钮粘贴先确认。
使用服务器默认 shell，不安装 zsh、不修改远端配置；仍仅支持密码认证，未增加 SFTP/私钥。

## Hermes 交互

根因：原先终端输出只提取颜文字，丢失了追问/授权 UI，同时生成中禁止普通消息发送。
聊天顶部新增“交互”，操作当前聊天的同一 PTY。识别到 Hermes 标准追问、危险命令、
sudo/secret 标题时自动打开，其他服务端文案可手动打开。
保留问题、命令、选项及服务器的实际按键规则；可用方向键、Space、Tab、Enter 或输入法回答。
客户端不会自动授权 root/sudo，也不会把系统密码写成聊天消息。关闭窗口不会替用户批准或取消。

交互按键不使用普通聊天的 Ctrl-U/括号粘贴包装；输入有序，发送前检查会话、socket、窗口有效期。
关闭、切会话、重联撤销旧输入；失败不重发。终端回放期间禁止向服务器发送历史查询回复。
普通聊天仍隐藏工具日志；等待用户回应不触发普通消息送达超时，回应后继续同步详细答案。

## 安全与边界

终端 WebView 只加载固定的本地资源，禁止文件/内容访问、外网导航和网络加载，
禁止 OSC52 读写手机剪贴板；远端输出只作为终端字节，不能注入 HTML 或 JavaScript。
字体/组件版本、来源、校验值与许可证随 APK 一同打包，见
[THIRD-PARTY.md](app/src/main/assets/terminal/THIRD-PARTY.md)。

SSH 回滚最多 3000 行；Hermes 延迟打开窗口前只保留最近 128 KiB 原始输出。
均只在内存中；进程被系统杀死后不会恢复密码或旧待发送输入。
只响应当前连接上的请求，不迁移网页版另一个独立 PTY 进程的等待状态。
旧 Android 设备应保持 Android System WebView 更新。
