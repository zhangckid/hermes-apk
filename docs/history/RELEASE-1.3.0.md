# catgo-gpt 1.3.0 聊天内追问与授权

版本：1.3.0-debug，versionCode 16。安装包：catgo-gpt-v1.3.0-debug.apk。
已核验与 1.2.3-debug 使用同一签名，可直接覆盖安装；保留服务器配置。

## 修改

- 移除聊天右上角“交互”按钮及自动弹出的 Hermes 终端窗口。Hermes 的问题直接显示在
  聊天内容中；文字问题可在底部输入框回答，单选和多选以原生按钮展示。
- 等待用户回答时，不再因“正在生成”禁用回答输入框；终端短暂重绘也不会打断文字输入。
  当前请求失效或尚未完整就绪时拒绝提交，输入框保留未发送的草稿。
- 危险命令在聊天内展示完整请求，只提供明确的“仅允许这一次”“拒绝执行”以及服务端支持时的
  “查看完整命令”。不提供永久授权，不自动确认；命令被截断时禁止允许执行。
- 密码/密钥使用单独的遮罩输入框，不进入聊天记录或 Android 状态保存，请求期间禁止截图。
  不会使用聊天登录密码代替远程系统密码，也不改变服务端自身的密码缓存行为。
- 非密码问题与已发送回答在当前应用运行期间保留，按会话隔离，最多 100 组；不额外写入服务端历史，
  应用重启后这些本地交互记录不保留。正文历史仍按原方式从服务器同步。
- 数字选项使用 Hermes 原始按键协议，不追加会误触下一步的 Enter。输入绑定当前请求和连接，
  过期、重复点击、切换会话或重联时不自动重发回答或授权。
- SSH 调试终端保持独立，保留 1.2.3 的原生单行输入框、密码遮罩和终端兼容性修复。

## 协议范围

当前服务通过 PTY 提供交互面板，并非结构化的提问 API。客户端根据已核对的 Hermes
CLI 方框面板和实际终端重绘内容，识别问题、危险命令及 sudo/密钥请求。
支持数字 1–9、0 的选项和单行文字回答。未知布局、不完整请求或无法确认的命令不会获得授权按钮；
若持续提示不能提交，需要在对应的网页版会话处理。无法迁移另一条独立 PTY 进程的待回应请求。

实现依据：[Hermes CLI 提问/授权](https://github.com/NousResearch/hermes-agent/blob/main/hermes_cli/cli_tui_mixin.py)、
[Hermes 密码与密钥面板](https://github.com/NousResearch/hermes-agent/blob/main/hermes_cli/cli_modal_mixin.py)。

- 使用 prompt_toolkit 生成实际 VT 初始绘制与增量重绘数据，验证中文、碎片 UTF-8、问题变化和密码面板。
  生成脚本为 `scripts/hermes-prompt-fixture.py`，测试使用已提交的固定数据，不依赖 Python 环境。
- 本机 WebSocket 回环验证原始问题、选择、中文回答、拒绝命令和密码提交字节，不执行真实 root 命令。
- 完整聊天页面测试验证正在生成时仍能回答、重绘时可继续输入、被拒绝的提交保留草稿。
- 18 项 Chromium 终端回归通过，包含真实本地 zsh、中文、原生输入桥接、渲染错误恢复。
- Debug APK、Release 未签名 APK 构建通过；Android lint 为 0 错误、35 警告、1 提示。

未连接用户的远程 Hermes/SSH 服务，也没有实体 Android 手机。以上结果不能代替用户手机上
Gboard、系统 WebView 和实际服务版本的端到端验收。

## 安装后检查

1. 覆盖安装新版，无需卸载或清空服务器配置。SSH 页可查看版本 1.3.0-debug。
2. 让 Hermes 提一个需要确认的问题：问题应出现在聊天内，不弹终端；用底部输入框回答。
3. 有选项时直接点击；多选先选择，再点“确认选择”。普通问题支持语音识别完成后自动提交。
4. 危险命令先查看完整内容，再手动允许一次或拒绝；密码只在专用遮罩框输入。
5. SSH 页面用 Gboard 输入 `echo 中文`，点“发送并回车”，检查回显。
